# SealLang

A programming language for when you want to code like a seal.

## What is it?

SealLang is an ocean-themed programming language where functions are called "dives," loops are "swim," structs are "pods," and print statements are "bark." Because why not?

## Why?

Because sometimes the world needs a language where you can literally tell a seal to bark at you through code.
